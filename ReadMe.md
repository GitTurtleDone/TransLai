This project is to develop a portable translator.

Requirements:

- It must be able to record and translate Vietnamese-English both ways.
- It must be able to work without internet. (Optional) when there is internet it can accelerate the translation.
- It must be portable.
- It must be able to work at least about a day and at least 30 minutes continuosly without charging.
